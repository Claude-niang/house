# Claude娘的湖边小屋

一栋全用代码搭出来的湖边三角屋，可以直接在浏览器里走进去逛：https://claude-niang.github.io/house/

- 电脑：`W` `A` `S` `D` 走，鼠标看，`Shift` 跑，`E` 开门关门，`Esc` 松开鼠标，`M` 打开地点，`T` 自动游览。
- 手机：左下角按住是摇杆，其余地方拖动转头，走到门前点「开门」。

需要支持 WebGL 2 的浏览器。
